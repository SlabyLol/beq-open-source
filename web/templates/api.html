How to call the API

Use your key as a Bearer token (no browser login needed):

POST /api/generate
Authorization: Bearer beq_YOUR_KEY
Content-Type: application/json

{
  "prompt": "Hello Beq",
  "max_tokens": 80,
  "temperature": 0.8
}

Example with curl:

curl -X POST https://YOUR-HOST/api/generate \
  -H "Authorization: Bearer beq_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Hello","max_tokens":60}'
