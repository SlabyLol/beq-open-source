About Beq

A real language model you can own, train and understand.

What is Beq?

Beq is a small GPT-style language model written entirely in pure PyTorch. It was created so anyone can have their own AI without relying on external APIs or closed models.

Core principles

  • Own the model – architecture + weights belong to you
  • No external AI APIs – everything runs locally
  • Transparent – clean, readable code
  • Open source – MIT license, free to use and modify

Technical details

  • Decoder-only Transformer (GPT-style)
  • Implemented from scratch in PyTorch
  • Character-level tokenizer (simple and fully self-contained)
  • Trained with standard next-token prediction
  • Web interface with FastAPI + plain HTML pages

How to train your own version

# 1. Put your text data into data/input.txt
# 2. Train
python train/train.py --data data/input.txt --max_steps 5000

# 3. Start the web server
python web/app.py

Repository

The full project is open source under the name beq-open-source. You can fork it, improve the architecture, train on your own data, and share your version.
